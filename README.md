# AERO-RL: Autonomous Micro-UAV Path-Planning & Collision Avoidance

A multi-tier Reinforcement Learning (RL) suite simulating micro-UAV (drone) navigation, obstacle avoidance, and path optimization in discrete and continuous spaces. Designed to demonstrate industry-grade AI path-planning skills for **ND Matrix**.

```
                +-----------------------------------------+
                |          Mission Planner UI             |

                +--------------------+--------------------+
                                     |
                                     v
                        +---------------------------+
                        |      Drone RL Agent       |
                        | (Q-Learning / PyTorch DQN)|
                        +------------+--------------+
                                     |
             +-----------------------+-----------------------+
             | State: Coordinates    | Action: Thruster      |
             | & Distance Telemetry  | Vector [U, D, L, R]   |
             v                       v                       v
    +-------------------------------------------------------------+
    |                        UAV Simulator                        |
    |      (1D Wire, 2D Grid Arena, 6D Continuous Rangefinder)     |
    +-------------------------------------------------------------+
```

## 🚀 Key Modules Built

1. **2D Visual Flight HUD (Browser)**: A web-based mission control panel utilizing HTML5 Canvas to show training episodes in real-time. Displays a dynamic V(s) value heatmap, policy arrows, path history, and speed controls.
2. **1D Position Hold Simulator (`drone_1d_rl.py`)**: A text-animated terminal simulation showing a drone learning to hover over a landing pad on a single-dimensional coordinate scale ($x$). Perfect for learning the basic math.
3. **2D Maze Search Simulator (`drone_2d_rl.py`)**: A terminal-based simulation showing Q-learning training progress inside an obstacle-dense grid, tracing out the optimal route under standard state constraints.
4. **Continuous DQN Navigator (`drone_dqn.py`)**: A deep reinforcement learning script utilizing **PyTorch** to train a neural network policy over a 6D continuous state space (incorporating 4 lidar distance sensor fields and continuous coordinate states).

## 📊 The Math Behind Drone Navigation (Explained simply)

### 1. The Bellman Optimality Equation
To navigate safely, the drone needs to learn which direction to fly from its current position. We store this knowledge in a database of state-action pairs $Q(s, a)$.
After taking action $a$ in state $s$, getting reward $r$, and ending up in state $s'$, the drone updates its beliefs using:

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right]$$

*   **$\alpha$ (Learning Rate)**: How fast the drone adopts new experiences.
*   **$\gamma$ (Discount Factor)**: How much the drone values future safety over instant gains.
*   **$r$ (Reward)**: Feedback from the world. Collision = $-40$; Goal = $+100$; Flying step = $-1$ (to save battery).

### 2. Exploration vs. Exploitation ($\epsilon$-Greedy Strategy)
*   **$\epsilon$ = 1.0 (Exploration)**: The drone wanders randomly to discover the layout of the environment.
*   **$\epsilon$ = 0.05 (Exploitation)**: The drone uses its learned Q-table to make the safest and fastest flight choices.
*   We slowly decay $\epsilon$ as episodes pass.

## 🛠️ Setup & Execution

### 1. Pre-requisites
Ensure Python 3.8+ is installed. Install core dependencies:
```bash
pip install numpy setuptools torch
```

### 2. Run the 1D Hover Simulator
To understand Q-learning math in its simplest form:
```bash
python drone_1d_rl.py
```

### 3. Run the 2D Terminal Simulator
To watch the drone learn to dodge walls in a grid:
```bash
python drone_2d_rl.py
```

### 4. Run the Continuous Deep Q-Network Agent
To train a continuous neural-network based flight controller:
```bash
python drone_dqn.py
```

### 5. Play with the Web Flight Arena
Open `index.html` directly in any web browser. Press **Auto-Train** to watch the drone learn path planning visually in real time!

## 📡 Hardware & Telemetry Bridge: Transitioning to Real Drones

In an industrial project , this software stack is scaled up using the following architecture:

*   **State Inputs**: The simple 4-way distance sensors in `drone_dqn.py` are mapped to real-time distance calculations from a **LiDAR sensor** (e.g. Velodyne) or depth maps generated by a stereo camera.
*   **Actuator Controls**: Instead of discrete buttons like Up or Down, the action output of the RL agent maps to setpoints on a flight controller (like **PX4** or **ArduPilot**) via **MAVLink** messages.
*   **Simulator Frameworks**: Standard testing is conducted in environments with realistic flight physics engines:
    *   **Gazebo / Webots**: Used for rigid-body physics, lidar telemetry, and motor rotor dynamics.
    *   **AirSim / Microsoft Unreal Engine**: Used for high-fidelity camera inputs and realistic vision-based reinforcement learning.
